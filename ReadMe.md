# MedicalBlocks: Patient Management System with React & PGlite

A modern, fully client-side patient management system running entirely in your browser using PGlite — a WebAssembly-powered PostgreSQL database.

## 📋 Features

- **In-Browser Database**: Full PostgreSQL database running directly in the browser with PGlite
- **Offline Support**: Works without an internet connection, with data persisted in IndexedDB
- **Multi-Tab Support**: Open multiple tabs to view and manage patient records with live reload
- **Patient Registration**: Complete form for adding patients with comprehensive medical information
- **Modern UI**: Clean, responsive interface built with React & ShadCn

## 📦 Installation

### Prerequisites

- Node.js (v16 or higher)
- npm (v7 or higher)

### Setup Steps

1. Clone the repository:

bash
git clone https://github.com/KaranMali2001/patient-management-system-pglite.git
cd patient-management-system-pglite 2. Install dependencies:

bash
npm install

3. Start the development server:

bash
npm run dev

4. Open your browser and navigate to http://localhost:5173

## 🔧 Available Scripts

In the project directory, you can run:

- pnpm run dev - Starts the development server
- pnpm run build - Builds the app for production
- pnpm run lint - Runs ESLint to check code quality
- pnpm run preview - Previews the production build locally

## 🧪 Technologies Used

- **ShadCn** - UI library
- **TypeScript** - Type safety and better developer experience
- **PGlite** - In-browser PostgreSQL database
- **React Router** - Application routing
- **Lucide React** - Icon library
